# clipbridge 0.3.0

Мост между ответами ассистента и локальным терминалом.

Как работает: ты копируешь из чата блок со скриптом (помеченный
`python bridge-run <имя>`), открываешь clipbridge, жмёшь «Запустить» —
программа извлекает скрипт, выполняет его в папке проекта и кладёт
структурированный отчёт обратно в буфер. Отчёт вставляешь в чат.

## Установка

    python -m venv .venv
    .venv\Scripts\activate          # Windows
    pip install -r requirements.txt

## Запуск

    python bridge.py

При первом запуске нажми «…» рядом со строкой пути и выбери папку
проекта. Путь сохранится и будет использоваться дальше.

## Тесты

    python run_tests.py

## Формат маркера

В моих ответах скрипт всегда выглядит так:

    ```python bridge-run stageNN
    ...код...
    ```

Имя: только `[A-Za-z0-9_-]`, до 64 символов.

## Вердикты отчёта

| Вердикт     | Что значит                                       |
|-------------|--------------------------------------------------|
| OK          | скрипт отработал, код возврата 0                 |
| ALREADY     | в stdout «УЖЕ ПРИМЕНЁН»                          |
| NO_ANCHOR   | в stdout «НЕ НАЙДЕН»                             |
| TIMEOUT     | превышен таймаут (300 с)                         |
| FAIL        | код возврата ≠ 0                                 |
| NOT_FOUND   | в буфере нет блока `python bridge-run`           |
| AMBIGUOUS   | в буфере несколько таких блоков                  |
| BAD_NAME    | имя скрипта недопустимо                          |

Скрипт может сам задать вердикт строкой `VERDICT: <WORD>`
(из набора OK/ALREADY/NO_ANCHOR/TIMEOUT/FAIL) — override приоритетен.

## Запуск без консоли

Двойной клик по `start.bat` в корне проекта — clipbridge запустится
без окна консоли (через `pythonw.exe`).

Если `pythonw` не в PATH, батник запустит через `python` — откроется
консоль, но программа стартует. Чтобы убрать консоль надёжно:
добавь папку Python в PATH или впиши полный путь к `pythonw.exe`
в `start.bat`.

## Уведомления

Пока окно clipbridge скрыто в трее, при срабатывании хоткеев
всплывают системные уведомления Windows:

- «Запускаю…» / «Запускаю тесты…» — в момент старта.
- «Готово: <вердикт>» / «Тесты: <вердикт>» — по завершении.

Если окно открыто — уведомления не показываются, статус виден
в самом окне.

## Хоткеи

Два глобальных хоткея, работают из любого приложения (WinAPI,
раскладко-независимо):

- **Ctrl+Alt+R** — основной: извлечь скрипт из буфера, запустить, отчёт в буфер.
- **Ctrl+Alt+T** — тесты: запустить файл тестов, отчёт в буфер.

Меняются через «Настройки».

## Тесты (функция clipbridge)

Кнопка «Тесты» в окне — ручной запуск. Хоткей Ctrl+Alt+T — то же из любого места.

В «Настройках» задаётся:
- запускать ли тесты автоматически после успешного main;
- файл тестов (по умолчанию `run_tests.py`);
- аргументы (например, `-v --tb=short`).
